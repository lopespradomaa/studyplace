
# AZ-104 – Azure Administrator Labs

This directory contains hands-on labs for the **AZ-104: Microsoft Azure Administrator** certification.

All labs are implemented using **command-line tools and Infrastructure as Code**, with a strong focus on real-world scenarios.

---

## Principles

- No Azure Portal
- Azure CLI only
- Bicep as Infrastructure as Code
- Git for version control
- Linux-based workflow (WSL)

---

## Tooling

- Azure CLI
- Bicep
- Git
- VS Code (connected to WSL)
